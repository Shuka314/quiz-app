# 問題アプリ（quiz-app）

単語アプリの間隔反復（SRS）を、単語以外の分野にも応用するための問題アプリです。
デッキ（教科）ごとに問題が分かれていて、お気に入りに登録した問題が毎日の復習に出てきます。

## 使い方

1. デッキ（教科）を選ぶ
2. 章（単元）の一覧から好きな章を選ぶ（章ごとに問題数・回答済み数・正答率・お気に入り数を表示。「すべての章」を選ぶと全問を通して解ける）。または「復習」「ランダム」を選ぶ
   - **章から解く**：その章の問題を順に解く。答えを選んだ瞬間に正誤と解説が出る。問題画面の下のボタンで前の問題・次の問題へ移動でき、回答済みの問題に戻ると自分の回答と解説がそのまま見える（再回答では数え直さない）
   - **復習**：お気に入り登録した問題のうち、今日が期日のものが出題される（間隔反復）
   - **ランダム**：全問題からランダムに出題
3. 間違えた問題は、その場でお気に入り登録を促す表示が出る（自動登録はしない）。登録すると復習の輪に入る

間隔の梯子は単語アプリと同じです（正解：0→1日、以降は2倍／不正解：間隔を半分にして再出題、lapses加算）。

## 進捗の保存（GitHub同期）

- 進捗（お気に入り・SRS状態・回答履歴）は、プライベートリポジトリ **Shuka314/vocab-data** の **quiz_progress.json** に保存されます（問題デッキとは分離）。
- アプリの設定画面で GitHub トークン（Fine-grained token、vocab-data の Contents: Read and write）を入力すると有効になります。単語アプリで使っているトークンが vocab-data にアクセスできるものなら、そのまま使えます。
- 端末内キャッシュ（localStorage）との併用です。オフライン時は端末内に保存され、オンライン時に同期します。
- 単語アプリと同じく、**同時に2つの端末・タブで開かない**でください（進捗が競合します）。

## デッキの追加方法

教科の追加に、アプリ本体の変更は要りません。

1. `decks/<subject>.json` を作る（下の形式）
2. `decks/index.json` の `decks` に `{"id": "<subject>", "file": "decks/<subject>.json"}` を1行足す

デッキJSONの形式：

```json
{
  "id": "japanese_grammar",
  "subject": "日本語",
  "title": "日本語文法",
  "description": "デッキの説明",
  "status": "placeholder",
  "questions": [
    {
      "id": "jg-001",
      "unit": "単元名",
      "question": "問題文",
      "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 0,
      "explanation": "正解の理由＋注意点",
      "distractor_notes": { "1": "その誤答を選んだときだけ出る専用コメント（任意）" }
    }
  ]
}
```

- `answer` は正解の選択肢の番号（0始まり）
- `distractor_notes` のキーは選択肢の番号（文字列）
