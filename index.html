間違えた問題

GitHub 同期（進捗の保存先）

進捗（お気に入り・復習の間隔・回答履歴）は、上のリポジトリの quiz_progress.json に保存されます。初期値は単語アプリと同じ保存先（Shuka314 / vocab-data）です。トークンが未設定の間は、この端末の中（localStorage）にだけ保存されます。

トークンの作り方：GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で、Repository access を vocab-data だけにし、Permissions の Contents を Read and write にして発行します。単語アプリで使っているトークンが vocab-data にアクセスできるものなら、そのまま同じものを貼れます。トークンはこの端末のブラウザ内にだけ保存され、GitHub 以外には送られません。

注意：単語アプリと同じく、同時に2つの端末・タブで開かないでください（進捗が競合します）。片方を閉じてから、もう片方を開いてください。

使い方
デッキ（教科）を選ぶと、章（単元）の一覧が出ます。各章には問題数・回答済み数・正答率・お気に入り数が表示され、好きな章をタップしてそこから始められます。「復習」「ランダム」も選べます。答えを選ぶと、その場で正誤と解説が出ます。問題画面の下のボタンで前の問題・次の問題へ移動でき、解き終わった問題に戻ると自分の回答と解説がそのまま見えます。問題の右上の星でお気に入りに登録すると、その問題は間隔反復（単語アプリと同じ梯子：正解で間隔が伸び、不正解で縮む）の対象になり、「復習」に出てきます。

デッキの追加
教科は decks フォルダの JSON ファイル1つで追加できます（decks/index.json に1行足すだけ）。アプリ本体の変更は要りません。
